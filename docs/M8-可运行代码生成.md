# M8 可运行代码生成与验证

## 目标

编码阶段不仅要输出文档，还要把代码真实写入磁盘，并在隔离环境中完成语法检查、启动验证和 pytest 测试，让系统可以交付一个可运行项目。

## 实现内容

1. 编码/测试阶段按 `[FILE] 路径` 格式生成代码文件。
2. 后端解析文件块并写入：

```text
backend/data/projects/{project_id}/code/
backend/data/projects/{project_id}/tests/
```

3. 每个生成项目使用独立虚拟环境，避免依赖污染平台本身。
4. 依赖安装只保留包名，不采用模型生成的旧版本号，避免与 Python 3.13 不兼容。
5. 运行验证支持：
   - Python 语法检查
   - 启动主入口（支持 `python -m app.main`）
   - 运行 pytest 测试
6. 编码阶段自动修复闭环：运行失败后把错误回传给开发 agent，重新生成，最多重试 3 轮。
7. 前端增加“生成代码”“运行验证”“运行测试”面板。

## 接口

```text
GET  /api/projects/{id}/code/tree
GET  /api/projects/{id}/code/file?path=...
POST /api/projects/{id}/code/run
POST /api/projects/{id}/code/test
```

## 验证情况

确定性样例验证通过：

- 手写 FastAPI 样例写入 `code/`。
- 独立环境启动成功，`/health` 可访问。
- pytest 测试通过。

MiMo 真实生成的项目已经能产出代码文件，但依赖安装受网络速度影响较大，自动修复闭环已启用，生成质量仍需继续通过提示词调优。
